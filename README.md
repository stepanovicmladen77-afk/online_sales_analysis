# Online Sales Analysis
Projekat za analizu prodajnih podataka, upravljanje proizvodima i korpom u Python-u uz korišćenje OOP koncepata i Git verzionisanja.

## Klase:
- *Product*: Sadrži atribute name, price, quantity i metode za prikaz i ažuriranje.
- *ProductManager*: Upravlja listom dostupnih proizvoda, dodavanjem, brisanjem i računanjem vrednosti inventara.
- *Cart*: Upravlja korpom kupca, dodavanjem artikala i izračunavanjem ukupnog iznosa za naplatu.
